# Security Policy

## Important

`ugm` runs as root and executes system commands (`useradd`, `usermod`, `chage`, `chpasswd`). It should only be used on systems where you trust the binary.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by opening a [security advisory](https://github.com/ariasmn/ugm/security/advisories/new) on GitHub.

Do **not** open a public issue for security vulnerabilities.

## Supported Versions

Only the latest release is supported with security updates.
